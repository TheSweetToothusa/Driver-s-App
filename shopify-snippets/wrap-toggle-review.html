Tap “See it wrapped” — these are live

The toggle moves into the card as a real button: outlined, quiet, and gold only while you are looking at the wrapped photo. Nothing can sit on the name again.

Five things changed

Position

In the card, not over it

Dropped the absolute positioning. The chip sits under the piece count, in normal flow, so it cannot overlap the name, the price or the ✓ at any width.

Colour

Not a second black pill

White with a hairline border, gold-filled only when it is showing the wrapped shot. The serving pill stays the one strong dark element on the card.

38 → 38 px

Same box in both states

It spans the text column, so the button does not resize when the label changes from “See it wrapped” to “See what’s inside”. No jump under your thumb.

The ✓ corner

The checkmark had it too

Building this mock-up turned up a second collision: once a basket is selected, the black ✓ sits on the price. The header now reserves that corner, so the price stays readable whether or not the card is picked.

Feedback

It answers the tap

Photo cross-fades, the arrow turns over, the chip fills gold. You can tell which of the two photos you are looking at without reading the label.

Getting it live

This page is a mock-up — the real builder still runs the old pill. The replacement block is written and tested, sitting in shopify-snippets/rosh-hashanah-wrap-toggle.html on the branch, because the builder page is HTML pasted into Shopify rather than code in a repo.
